# Guia de publicação

Consulte `README.md` para o passo a passo, criação do banco, `.env`, cadastramento do primeiro produtor e promoção segura a administrador.

- ZIP de hospedagem: `AgroVigia_RO_PARA_HTDOCS.zip` — conteúdo diretamente dentro de `htdocs`.
- SQL: `database/hosting.sql` dentro do ZIP completo (`AgroVigia_RO_COMPLETO.zip`), para importar em phpMyAdmin.
- `.env.example`: modelo. **Não está preenchido com credenciais reais**.
- Não importar dados de teste nem criar contas de senha padrão.
